# Student Management System

A web-based Student Management System developed using Python and Django.

## Features
- Student registration and management
- View student details
- Update student information
- Delete student records
- Trash management
- About and Contact pages

## Technologies Used
- Python
- Django
- HTML
- CSS
- SQLite

## Project Structure
- `config/base/` – Django application
- `config/config/` – Project settings and URL configuration
- `config/manage.py` – Django management utility

## Installation

1. Clone the repository.
2. Create and activate a virtual environment.
3. Install dependencies:

   `pip install -r requirements.txt`

4. Run migrations:

   `python config/manage.py migrate`

5. Start the development server:

   `python config/manage.py runserver`
